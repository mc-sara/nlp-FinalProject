## 5. 恢复后要做的第一件事

1. 重新拉起机器，确认 `/root/private_data` 还在（NFS 上的数据在停机后通常保留）。
2. 若在：把 `p2_scnet/` 下 `p2.py`、`fewshot.py`、`p2_collection_patch_v3.py`、`vendor/p1/tieba_env/scenarios.py` 同步进 `p2/scnet-backup-20261029`，补上这次漂移。
3. 若不在：按 `p2/scnet-backup-20261029` 重建环境（见 `p2_scnet/DEPLOYMENT_20261029.txt`），模型从 `Qwen/Qwen3.5-9B` 重新下载（19.33 GB）。
4. 继续 PLAN §4.2 顺序：D2 few-shot 门槛（`fewshot.py`，用 `p3_review_20261031/corrected_demos.jsonl`）→ D1 采样表 → D3 基线 → D4 训练 → D5 三组对照 → D6 真实确认。
